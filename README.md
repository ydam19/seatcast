# 앉을각

지하철에서 어느 칸, 어느 문 앞에 서야 빨리 앉을 수 있는지 알려주는 서비스입니다.

노선, 시간, 탄 역, 탄 위치(예: 3-2)를 고르면 앞으로 몇 정거장 안에 그 칸에서 자리가 날 가능성을 보여주고, 더 유리한 칸을 추천합니다. 첫 버전은 2호선만 다룹니다.

## 접근 방식

1. **역별 하차 인원 예측**: 역, 방향, 시간대, 요일 구분으로 하차 인원을 예측합니다.
2. **열차 혼잡도**: 서울교통공사 혼잡도(좌석이 모두 차면 34%)로 그 시간대 열차에 빈자리가 있는지 판단합니다.
3. **칸별 분배**: 역마다 계단·에스컬레이터·환승 통로와 가까운 칸·문에 하차 인원이 몰린다고 보고 칸별로 나눕니다. 이 단계는 공개된 칸별 실측 데이터가 없어 가정이며, 직접 탑승 관찰로 검증합니다.
